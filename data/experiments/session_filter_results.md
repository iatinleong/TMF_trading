# 時段濾網 A/B 測試（breakout 策略）

## 1. 資料實際涵蓋的 session（先驗證，不預設）

- 實際資料型態：**day_and_night**；本次檢查 `data/MTX_60min_real.csv` 與 `data/TX_60min_real.csv`，兩者時間戳分布一致。
- 期間：**2026-05-22T16:00:00 ~ 2026-07-03T13:45:00**
- 總 bar 數：**551**
- 實際出現的 bar close 時間：**00:00, 01:00, 02:00, 03:00, 04:00, 05:00, 09:45, 10:45, 11:45, 12:45, 13:45, 16:00, 17:00, 18:00, 19:00, 20:00, 21:00, 22:00, 23:00**
- 日盤 bar：**09:45, 10:45, 11:45, 12:45, 13:45**
- 夜盤 bar：**00:00, 01:00, 02:00, 03:00, 04:00, 05:00, 16:00, 17:00, 18:00, 19:00, 20:00, 21:00, 22:00, 23:00**
- 每個上述時間在資料中都出現 **29 次**，表示這份樣本同時含有日盤與夜盤，而不是只有日盤。

## 2. 方法說明

- breakout 訊號在當前 bar 收盤才成立，交易必須在**下一根 bar 開盤**才執行。
- 因此本次『時段濾網』不是事後把成交單切掉，而是先看**下一根將成交的 bar 屬於哪個時窗**，再在訊號層直接抑制 long/short mask，最後才呼叫 `_apply_signal_columns`。
- 指標沿用既有 breakout 參數（MA 5/20/60、SL 150.0、TP 500.0）。
- Total Return %、Sharpe Ratio、max_drawdown_pct 與不穩定 Sharpe 旗標，皆直接重用 `backend.experiments.proper_evaluation_with_dsr` 的既有函式。
- 低信度規則：**n_trades < 10**。
- 與先前報告一致，只有 Sharpe **明顯高於 4.18**（先前 12 次 trial 的 Prado 純運氣門檻）才值得被視為可能不是雜訊；本次其實又多做了 7 個新 trial，因此這個 4.18 其實已偏寬鬆。
- Baseline 原始可成交訊號（以『下一根將成交的 bar close 時間』統計）分布：**01:00=2, 02:00=1, 03:00=3, 04:00=1, 10:45=1, 11:45=3, 12:45=3, 13:45=2, 17:00=2, 20:00=1, 21:00=1, 23:00=4**。
- 上面這個分布裡**沒有 09:45 與 16:00**，代表在這段樣本中，baseline breakout 根本沒有產生『下一根會在兩個 session 開盤第一根成交』的訊號；所以相關 open-filter 變體若與 baseline 完全相同，是資料本身告訴我們『這個風險點在此樣本沒有被觸發』，不是程式失效。

## 3. 測試變體

- **A. Baseline**：不做時段過濾，保留所有 breakout 訊號。
- **B. 僅做日盤進場**：只保留下一根會在日盤 bar 開盤成交的訊號。
- **C. 僅做夜盤進場**：只保留下一根會在夜盤 bar 開盤成交的訊號。
- **D. 排除日盤開盤第一根**：排除下一根會在日盤第一根（09:45 bar）開盤成交的訊號。
- **E. 排除夜盤開盤第一根**：排除下一根會在夜盤第一根（16:00 bar）開盤成交的訊號。
- **F. 排除兩個 session 開盤第一根**：同時排除下一根會在 09:45 或 16:00 bar 開盤成交的訊號。
- **G. 排除兩個 session 尾段**：排除下一根會在 13:45 或 05:00 bar 開盤成交的訊號（接近 session 收尾）。
- **H. 僅做中段時窗**：只保留非開盤第一根、也非最後一根的中段時窗。

## 5. 結論

- 這份資料**確定同時含日盤與夜盤**，所以本次是用 session-aware 的 entry 時窗去做真實訊號層測試，而不是事後切交易。
- 若某變體看起來比 baseline 好，仍要先看它是否只是『少數幾筆』造成；表格裡凡是 `低信度=是` 都必須保守解讀。
- 若 Sharpe 被標成 `不穩定(近零變異)`，代表報酬標準差接近零、比例會失真，不能把那個數字當真優勢。
- 就算某些時段濾網略微改善 Total Return 或 max drawdown，只要 Sharpe 沒有越過 4.18，就不足以宣稱找到穩健 alpha；更別說這次又新增了額外 trial，真實門檻只會更高。
