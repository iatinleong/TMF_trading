# Breakout Regime Filter A/B 測試

## 1. 實驗設定
- 商品：MTX、TX
- 資料期間：2026-05-22 16:00:00 ~ 2026-07-03 13:45:00
- 每個商品 K 棒數：約 551 根 60 分 K
- 基準策略：5MA / 20MA crossover breakout，訊號於收盤確認、下一根開盤進場
- 風控：SL=150 點、TP=500 點
- 關鍵指標定義：『虧損單中同棒停損占比』= 虧損單中，`exit_reason=stop_loss` 且 `holding_bars == 0` 的比例（真正同一進場棒就被打掉）
- Regime filter 的正確做法：先在訊號棒上過濾 long_mask / short_mask，再交給 `_apply_signal_columns`，沒有 retroactive slicing
- Sharpe 判讀門檻：沿用 `data/experiments/proper_evaluation_with_dsr.md` 的純運氣門檻 **4.18**；若未明顯超過，不視為可信 alpha
- 樣本警語：樣本期間僅約 30 個交易日、每個商品 baseline 只有 24 筆交易；任何濾網造成的勝率、Sharpe 與同棒停損比例改善，都可能受小樣本影響。

## 2. 變體定義
- **A. Baseline**：原始 breakout 訊號，無 regime filter。
- **B. ADX(14) > 20**：僅在訊號棒 ADX(14) > 20 時保留 MA crossover。
- **C. ADX(14) > 25**：僅在訊號棒 ADX(14) > 25 時保留 MA crossover。
- **D. ATR 擴張**：僅在訊號棒 ATR(14) > ATR(14) 自身 60 根 rolling median 時保留訊號。
- **E. ADX>20 且 ATR 擴張**：同時要求 ADX(14) > 20 與 ATR(14) 高於自身 60 根 rolling median。

## 4. 重點觀察
- Baseline 與前述診斷一致：MTX 24 筆、同棒停損占比 78.9%；TX 24 筆、同棒停損占比 73.7%。
- **ADX>20 並沒有降低 whipsaw**：MTX 同棒停損占比從 78.9% 升到 86.7%，TX 也從 73.7% 升到 80.0%；Total Return 與 Sharpe 也同步惡化。
- **ADX>25 是唯一在 MTX / TX 兩邊都真正降低 same-bar stop-out 的濾網**：MTX 從 78.9% 降到 62.5%，TX 從 73.7% 降到 62.5%；交易數則從 24 壓到 10 / 10 筆。
- **ATR 擴張沒有明顯幫助**：MTX/TX 同棒停損占比只有到 80.0% / 80.0%，仍高於或接近 baseline，且報酬與 Sharpe 都更差。
- **組合濾網（ADX>20 + ATR 擴張）最不理想**：MTX/TX 同棒停損占比反而升到 90.0% / 90.0%，Sharpe 仍是 -1.80（距離 4.18 尚差 5.98） / -1.77（距離 4.18 尚差 5.95）。
- 以 **Total Return / Sharpe** 看，兩個商品最佳的都是 **C. ADX(14) > 25 / C. ADX(14) > 25**：MTX Total Return -0.67%、Sharpe -1.02（距離 4.18 尚差 5.20）；TX Total Return -0.58%、Sharpe -0.89（距離 4.18 尚差 5.07）。
- **沒有任何變體接近 4.18 的 Prado 純運氣門檻**：本次最佳 Sharpe 也只有 -0.89 左右，仍遠低於 4.18，且甚至還是負值。

## 5. 結論
- **是否有明顯降低 same-bar stop-out？** 有，但只有 **ADX>25** 在 MTX/TX 兩邊都明確下降；其他 3 個濾網不是無效，就是更差。
- **是否改善 Sharpe / Total Return？** ADX>25 有『小幅改善但仍為負值』：它把虧損收斂一些，但策略整體仍然虧錢，還談不上可用。
- **是否接近或超過 4.18 運氣門檻？** 沒有；全部變體都遠低於 4.18，因此不能宣稱找到可信的新 alpha。
- 建議：若要延伸研究，只值得把 ADX>25 帶去更長期間 / 樣本外驗證；ATR 擴張與組合濾網目前沒有保留價值。
