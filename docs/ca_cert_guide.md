# 安裝前必做：群益 CA 憑證申請 + 連線測試

在安裝 TMF 交易系統之前，**你的群益期貨帳號必須先在這台電腦完成兩件事**：申請 CA 憑證、
做一次官方連線測試。這是群益（Capital）自己規定的雙因子登入機制，跟我們的安裝程式無關，
沒做完這兩步，裝好軟體也連不上。

整個過程大約 10~15 分鐘，只需要做**一次**（除非換電腦，或憑證過期）。

## 開始之前，請準備好

- 你的群益期貨帳號（身分證字號 + 密碼）
- 綁定的手機（會收簡訊驗證碼）
- 就是接下來要安裝交易軟體的**這一台電腦**（憑證是綁定電腦的，不是隨身碟或雲端帳號）

## 第一步：申請 CA 憑證

1. 打開瀏覽器，搜尋「群益金融網」，進入官網（capital.com.tw）
2. 找到「憑證專區」→「AP 軟體憑證」
3. 點選「立即申請/展延」，下載「憑證精靈」（程式名稱通常是 `RAWinApp`）
4. 打開下載好的憑證精靈，輸入你的**身分證字號**與**密碼**登入
5. 點「申請」
6. 會出現「CA 憑證申請同意書」，仔細看過後點「我同意」，網頁會自動跳到「憑證作業」頁面
7. 依序：「驗證身分」→「寄發驗證碼」→「收取驗證碼」（看手機簡訊）→ 回到憑證精靈畫面
8. 輸入收到的驗證碼，等 5~20 秒讓它下載憑證資料
9. 點「檢測憑證請按此」

**成功的樣子**：畫面會顯示一個表格，「狀態」欄位是綠色勾勾＋「此電腦已安裝您的有效憑證」，
到期日大概是一年後。像這樣（範例）：

```
憑證發給      序號       發放日        到期日        狀態
96571013     53F08B5E   2026-07-07   2027-07-07   ✅ 此電腦已安裝您的有效憑證
```

看到這個畫面就代表第一步完成了。**但還沒結束**——很多人以為裝好憑證就可以用了，
其實還有第二步，沒做的話一樣連不上（登入會出現錯誤代碼 `602`）。

## 第二步：官方連線測試（SKCOMVerifyDJ）

依主管機關規定，正式使用 API 前必須做一次連線測試。

1. 到群益「API 下載專區」，下載「連線測試小程式」，檔名是 `SKCOMVerifyDJ.exe`
2. 打開它，做「雙因子登入」
3. 如果你有國內期貨帳號（微台/小台/大台都算），做「下單測試(國內期貨)」這一項
   （如果只有證券帳號沒有期貨帳號，才需要做「下單測試(證券)」那一項）
4. 完成後可以「查詢測試紀錄」，確認有沒有驗證成功

**成功的樣子**：測試紀錄會顯示類似這樣的文字：

```
登入成功
已完成驗證國內證券下單, YYYY/M/D 下午 HH:MM:SS
已完成驗證國內期貨下單, YYYY/M/D 下午 HH:MM:SS
```

看到「已完成驗證國內期貨下單」這行，就代表兩步都做完了，可以安裝交易軟體了。

## 常見問題

**Q: 憑證裝好了，但軟體登入還是顯示 602？**
A: 90% 是因為第二步（SKCOMVerifyDJ 連線測試）還沒做，或者做的是「證券」測試而不是
「國內期貨」測試。國內期貨帳號一定要做「下單測試(國內期貨)」這一項。

**Q: 兩步都做完了，還是 602？**
A: 檢查一下交易軟體是不是安裝正確——正常安裝好的版本會在你**目前登入 Windows 的這個使用者**
底下自動啟動（開始選單有捷徑、工作排程器裡有一個叫 `TMF-Trading-API` 的項目，登入時自動執行）。
如果是用其他機制（例如開機時用系統管理員/SYSTEM 身分背景啟動）去跑這個程式，
群益的憑證驗證機制認不出來，一樣會是 602——這是我們安裝程式已知且已經修正的地方，
如果你是用官方安裝程式裝的，不會遇到這個問題。

**Q: 憑證多久要重新申請？**
A: 憑證上顯示的「到期日」到了之前，重新走一次第一步（申請）就好，通常不用重做第二步的連線測試，
除非群益系統另外通知你需要重新驗證。

**Q: 我可以在另一台電腦（例如筆電）重複使用同一個帳號嗎？**
A: 可以，但憑證是綁電腦的，換一台電腦要重新走一次第一步、第二步，不能把憑證複製過去。
